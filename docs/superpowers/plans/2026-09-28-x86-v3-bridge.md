# X86 v3 透明网桥构建 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 基于 v2 新增可供刷机后配置透明网桥代理的 v3 工作流。

**Architecture:** 保留 v2 的 x86、Passwall、ZeroTier 和管理 IP 配置。v3 显式选择 iptables 透明代理和桥接模块，构建时验证配置，网口和运行规则由用户刷机后配置。

**Tech Stack:** GitHub Actions YAML、OpenWrt Kconfig、POSIX shell。

## Global Constraints

- 不修改 X86-v2.yml 或已有用户文件。
- 必须包含 `CONFIG_PACKAGE_kmod-br-netfilter=y`。
- 不猜测三个物理端口的设备名，不预先开启桥接流量过滤。
